# VR肘屈曲課題（Meta Quest 3）

座位・机上で行う肘屈曲課題です。VR上の腕は、実際の肘屈曲角度に倍率（ゲイン）をかけて表示されます。
Quest 3 のブラウザで開くだけで動きます（アプリのインストール・開発者モードは不要）。ハンドトラッキング推奨。

## 課題の内容（初期設定）
「肘を90°曲げてください」と指示し、各条件3試行ずつ行います。

| 条件 | 倍率 | 90°曲げたときの見え方 |
|---|---|---|
| 1：一致 | ×1.00 | 90° |
| 2：過小表示 | ×0.50 | 約45° |
| 3：過大表示 | ×1.67 | 約150° |

倍率・試行数・指示角度・実施順（固定／ブロック順ランダム／全試行ランダム）は開始画面で変更できます。

## 流れ
1. 課題側の肘を机につき、前腕を机に置いた姿勢（開始肢位）をとる
2. 反対側の人差し指で肘頭に触れて2秒静止 → 肘の位置と開始肢位を登録
3. 反対の手を下ろすと課題開始（実際の腕は見えず、VR上の腕のみ表示）
4. 開始肢位で1秒静止 → 「90°曲げてください」 → 曲げて保持（既定1秒）すると記録 → 「戻してください」
5. 倍率の切り替えは、腕が開始肢位にある間に行います（切り替えが見えないように）

## 角度の推定方法
「登録した肘の位置 → 手首」のベクトルが、開始肢位から何度回転したかを肘屈曲角とします（開始肢位＝0°）。
肘が机から浮く・ずれると誤差になります。計測機器としての妥当性は未検証です。

## 出力（CSV）
- **試行データ**：trial, condition, rep, gain, instructed_deg, real_deg（保持時の実際の角度）, shown_deg（表示角度）, peak_real_deg（最大角度）, time_s（指示から保持判定まで）, status（ok / timeout）, input（hand / controller）
- **時系列データ**：50Hzで time_s, trial, condition, gain, phase, real_deg, shown_deg, tracked

## GitHubで公開する手順（初めての方向け）
1. https://github.com でアカウントを作成し、ログインします。
2. 右上の「＋」→「New repository」。名前（例：`vr-elbow`）を入れ、**Public** を選んで「Create repository」。
3. 「uploading an existing file」をクリックし、`index.html` と `README.md` をドラッグして「Commit changes」。
4. 「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」。
5. 1〜2分後、`https://（ユーザー名）.github.io/vr-elbow/` で公開されます。Quest 3 のブラウザで開き、ブックマークしてください。

修正版は同じリポジトリに `index.html` を上書きアップロードすれば更新されます。

## 注意
- 安定した椅子で、周囲に物がない状態で行ってください。めまい・気分不良・痛みが出たら中止してください。
- 研究で用いる場合は、ゴニオメーター等との比較による妥当性・信頼性の検証を行ってください。
